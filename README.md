# GUC Gymnastique & Danse — site V1

Site statique prêt pour GitHub Pages.

## Mise en ligne

1. Créer un dépôt GitHub.
2. Déposer **le contenu de ce dossier à la racine du dépôt**.
3. Aller dans **Settings > Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner `main` puis `/ (root)`.
6. Enregistrer. GitHub affichera ensuite l’adresse du site.

## Pages

- `index.html` — accueil
- `activites.html` — GR, GEG, place de la danse
- `cours-tarifs.html` — créneaux, âges/niveaux, tarifs
- `club.html` — projet et encadrement
- `faq.html` — questions fréquentes
- `inscription.html` — Google Form intégré
- `mentions-legales.html` — structure juridique à compléter

## Points à valider avant publication

- Les repères d’âge affichés pour chaque créneau.
- Les diplômes et présentations exactes des deux éducatrices.
- Le contenu exact de la cotisation et les frais complémentaires éventuels.
- Les mentions légales : siège, RNA, SIREN, responsable de publication.
- Le nom de domaine définitif si vous en utilisez un.

## Images

La V1 utilise des images externes afin de rester légère.
Pour une version finale robuste, téléchargez les images autorisées dans `assets/images/`
et remplacez leurs URL par des chemins locaux.
